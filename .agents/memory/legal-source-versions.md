---
name: Legal-source version pitfalls
description: Reading redirected municipal sources and historical commencement evidence
---

A municipal-code section URL can redirect to the entire current chapter. An
effective-date section in an earlier council packet can be absent from that
current codification. The earlier draft's date is not sufficient evidence of
commencement for a later amended provision, even if its core prohibition is
unchanged.

**Why:** Berkeley's public code returned the whole amended chapter for its old
effective-date section URL; that chapter confirms amendment adoption but omits
the old deferral. Treating the earlier packet as the latest version would claim
a precise historical start without evidence.

**How to apply:** Read the returned version and adoption references, not just
the requested URL. Keep current adoption proof distinct from historical
commencement proof, and retain unknown when the latter cannot be established.
